# toy-order-service

Как добавляем изменения:
1) Создаем ветку от акутального мейн с номером тикета в проекте и кратким описанием задачи, например #1-create-order-service-skeleton
2) В ветке добавляем все нужные изменения.
3) Коммиты пишем по формату "номер_тикета глагол описание", например "#1 Add maven dependencies to pom.xml"
4) Пушим ветку, создаем пулреквест в мейн, ставим Егора в ревьюверы. Можешь скинуть ссылку на ПР в телегу. 
5) Егор (опционально) пишет комменты, мы правим или СПОРИМ, когда все ок, Егор аппрувит, Миша делает мердж в мейн.
6) При мердже можно поставить галку "удалить ветку"
